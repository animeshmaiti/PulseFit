# PulseFit

PulseFit is an Android workout and exercise tracking application built with Kotlin and Jetpack Compose.
The app allows users to create and manage exercises, build custom workouts, configure exercise durations and breaks,
and perform guided workout sessions with countdowns, timers, sounds, and calorie estimation.This is a offline app so it is
totally free and no need to login or signup. All data is stored locally on the device using Room Database.

---

## Features

### Exercise Management

- Create custom exercises
- Edit existing exercises
- Delete exercises
- View exercise details
- Categorize exercises
- Configure exercise duration
- Store MET values for calorie estimation

### Workout Management

- Create custom workouts
- Add exercises to a workout
- Reorder exercises(soon)
- Configure individual exercise durations
- Configure breaks between exercises
- Edit existing workouts
- Delete workouts
- Mark workouts as favorites
- View workout details and exercise timeline

### Workout Sessions

PulseFit provides a guided workout session flow:

```text
Workout Setup
      ↓
3 - 2 - 1 Countdown
      ↓
Exercise
      ↓
Break (if configured)
      ↓
3 - 2 - 1 Countdown
      ↓
Next Exercise
      ↓
...
      ↓
Workout Finished
```

### Calorie Estimation

PulseFit estimates calories burned using:

- Exercise MET value
- User body weight
- Exercise duration
